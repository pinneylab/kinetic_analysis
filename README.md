# Pinney Lab - Kinetic Analysis Package

This package provides tools for analyzing enzyme kinetics data.

## Installation

To install the package, clone from github:
`git clone https://github.com/pinneylab/kinetic_analysis.git`

Then, navigate to the parent directory and install using pip:
`pip install -e kinetic_analysis/`

## Usage

To use the package, import it in your Python code:

```python
from kinetics import *
```
